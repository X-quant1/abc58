## 💡 峰值背离检测逻辑

### 顶背离（做空信号）

```
1. 找到价格的局部峰值点
2. 比较相邻两个峰值：
   - 前一个峰值价格 > 再前一个峰值价格（价格创新高）
   - 前一个峰值DIF < 再前一个峰值DIF（DIF未创新高）
3. 当前K线是峰值点 → 触发做空信号
```

### 底背离（做多信号）

```
1. 找到价格的局部谷值点
2. 比较相邻两个谷值：
   - 前一个谷值价格 < 再前一个谷值价格（价格创新低）
   - 前一个谷值DIF > 再前一个谷值DIF（DIF未创新低）
3. 当前K线是谷值点 → 触发做多信号
```

### 峰值检测算法

```python
def find_peaks(data, window=3):
    """找到局部峰值"""
    peaks = []
    for i in range(window, len(data) - window):
        is_peak = True
        for j in range(i - window, i + window + 1):
            if j != i and data[j] >= data[i]:
                is_peak = False
                break
        if is_peak:
            peaks.append((i, data[i]))
    return peaks
```

**窗口=3 的含义**：当前K线的价格必须比前后各3根K线都高，才被认为是峰值。

| 峰值窗口 | 15m交易数 | 15m净收益 | 30m交易数 | 30m净收益 |
